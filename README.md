# Dataraflow Data Science & Machine Learning Journey

Welcome to my Dataraflow learning repository.

This repository documents my journey through the **Dataraflow Data Science and Machine Learning Program**, a 6-month program designed to build practical skills in data science, machine learning, programming, research, and problem-solving.

I created this repository to keep track of my progress, document the work I complete throughout the program, and have a record of what I learn along the way.

## About the Dataraflow Program

The Dataraflow program is a **6-month Data Science and Machine Learning training program** focused on building a strong foundation in programming, data analysis, machine learning, and research through practical assignments and take-home tasks.

Rather than simply learning concepts, the program encourages us to apply what we learn through projects, exercises, research, and problem-solving.

## Why I'm Doing This

My background is in **Chemistry**, but I am interested in combining chemistry with technology, particularly **Data Science, Machine Learning, and eventually Cheminformatics**.

I joined Dataraflow to strengthen my technical foundation and develop the skills needed to work with data and machine learning.

This repository is therefore more than just a collection of assignments. It is a documentation of my transition into data science and my progress toward applying computational methods to chemistry.

> **Tools change, but the ability to think, understand, and solve problems lasts.**

## Learning Journey

I am documenting my progress week by week, including take-home assignments, projects, research work, and other exercises completed during the program.

### Week 1 — Overview, Introduction & Setup

Topics covered:

- Introduction to Data Science
- Introduction to Machine Learning
- Overview of the Data Science workflow
- Python setup and environment
- Python fundamentals
- Data types
- Comparison operators
- Conditional statements
- Loops
- Functions
- Lambda functions
- `map()` and `filter()`
- Python methods

**Focus:** Building a foundation in Python and understanding the broader Data Science and Machine Learning landscape.

---

### Week 2 — Python II & Object-Oriented Programming

Topics covered:

- Advanced Python concepts
- Functions and programming concepts
- Object-Oriented Programming (OOP)
- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Iterators
- Scope

**Focus:** Developing a stronger understanding of Python and learning how to structure programs using Object-Oriented Programming.

---

### Week 3 — Python III & Introduction to SQL

Topics covered:

- More advanced Python concepts
- Working with data in Python
- Introduction to databases
- Introduction to SQL
- SQL queries
- Filtering and sorting data
- Aggregate functions
- Data analysis using SQL

**Focus:** Connecting programming skills with data manipulation and database querying.

---

### Weeks 4–5 — Research

Weeks 4 and 5 focused more heavily on **research and exploration**.

This stage involved moving beyond simply learning technical concepts and thinking about how Data Science and Machine Learning can be applied to real-world problems.

Areas explored include:

- Research methodology
- Identifying problems that can be addressed using data
- Reviewing existing research
- Exploring potential project ideas
- Understanding how to approach a research problem
- Connecting technical skills with domain-specific problems

**Focus:** Developing the ability to identify meaningful problems, investigate existing work, and think about how data and machine learning can be applied to them.
